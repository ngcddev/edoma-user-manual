asignados, el período activo y tus tareas pendientes del día, con accesos
directos a cada módulo.

export function ActionCard({ icon: Icon, tone, title, subtitle, action }) {
  const toneClass = { primary: 'bg-fd-primary/10 text-fd-primary', success: 'bg-fd-success/10 text-fd-success', info: 'bg-fd-info/10 text-fd-info', warning: 'bg-fd-warning/10 text-fd-warning' }[tone];
  const btnClass = { primary: 'border border-fd-border', success: 'bg-fd-success/15 text-fd-success', info: 'bg-fd-primary text-fd-primary-foreground', warning: 'bg-fd-warning/15 text-fd-warning' }[tone];
  return (
    <div className="rounded-lg border border-fd-border p-3">
      <div className={`mb-2 flex size-8 items-center justify-center rounded-lg ${toneClass}`}><Icon className="size-4" /></div>
      <div className="text-sm font-medium">{title}</div>
      <div className="mb-2 text-xs text-fd-muted-foreground">{subtitle}</div>
      <span className={`inline-flex rounded-lg px-3 py-1 text-xs font-medium ${btnClass}`}>{action}</span>
    </div>
  );
}

## ¿Qué encontrarás aquí?

- **Información del Docente**: tu último curso consultado (ejemplo: `2-1`),
  el período académico activo (ejemplo: `Primer Periodo`) y los cursos que
  tienes asignados, cada uno como una tarjeta (ejemplo: `2-1`, `4-1`, `6-2`,
  `10-2`).
- Un panel a la derecha con el **período activo del año** (ejemplo:
  `Primer Periodo 2026`) y la confirmación de que el sistema está listo
  para registrar asistencias y notas.
- **Tarjetas de resumen**: número de **Cursos**, **Estudiantes** a tu cargo y
  **Clases hoy**.
- **Accesos directos** a cada módulo:

| Módulo | Función |
| --- | --- |
| [Registrar Notas](/sistema-gestion-escolar/profesor/modulos/registrar-notas) | Evaluaciones y calificaciones de tus estudiantes |
| [Registrar Asistencia](/sistema-gestion-escolar/profesor/modulos/registrar-asistencia) | Registro diario de asistencia por clase |
| [Mirar Horario](/sistema-gestion-escolar/profesor/modulos/horario) | Consulta de tus clases de la semana |
| [Observador](/sistema-gestion-escolar/profesor/modulos/observador) | Registro de anotaciones a un estudiante |
| [Director de Grupo](/sistema-gestion-escolar/profesor/modulos/direccion-de-grupo) | Gestión integral del curso que diriges (si aplica) |
| [Rendimiento](/sistema-gestion-escolar/profesor/modulos/rendimiento) | Consulta del desempeño de tus cursos |

- **Pendientes de hoy**, a la derecha: **Asistencia** y **Notas** por
  registrar hoy, tu **Próxima clase**, un acceso directo para **Agregar
  observación**, otro para **Director de grupo** (si tienes un curso a
  cargo), y **Ver rendimiento** (con un contador en rojo si hay cursos por
  debajo del promedio, ejemplo: `2 cursos por debajo del promedio`). Si no
  hay clases programadas (fin de semana o día sin horario), cada ítem
  muestra **"Fin de semana"** en su lugar, y al final aparece un mensaje de
  ánimo como **"Buen ritmo hoy"**.

<Callout type="info">
  Cuando **otro docente te delega una clase** (ejemplo: `Asistencia — 3-1
  Matemáticas · Clase delegada por Ana Ruiz` — ver el detalle en
  [Horario](/sistema-gestion-escolar/profesor/modulos/horario#delegar-una-clase-a-otro-docente))
  o **Administración te otorga un registro extemporáneo de asistencia**
  (ejemplo: `Asistencia — 2-1 Ciencias Naturales · Registro extemporáneo
  habilitado por Administración` — ver el detalle en
  [Registrar asistencia](/sistema-gestion-escolar/profesor/modulos/registrar-asistencia)),
  ese aviso aparece dentro de **Pendientes de hoy**, en el ítem de
  **Asistencia** de esa clase — con acceso directo para entrar a
  registrarla.
</Callout>

<Steps>
<Step>

### Revisa el período activo

Confirma en la parte superior que el **Período activo** corresponde al
período académico vigente antes de registrar notas o asistencia.

</Step>
<Step>

### Revisa tus pendientes de hoy

En **Pendientes de hoy**, verifica si tienes asistencia o notas por
registrar y cuál es tu próxima clase.

</Step>
<Step>

### Entra al módulo que necesites

Haz clic en la tarjeta o el ítem correspondiente (**Entrar**, **Ir**,
**Ver**, **Anotar** o **Abrir**) para ir directo al módulo.

</Step>
</Steps>

<Callout type="warn">
  Si ves el aviso **"No se puede subir notas porque no estás dentro del
  rango de fecha estipulada por la ADMINISTRACIÓN"**, significa que el
  período de registro de notas está cerrado. Contacta al equipo
  Administrativo para que ajuste las fechas en Períodos.
</Callout>
