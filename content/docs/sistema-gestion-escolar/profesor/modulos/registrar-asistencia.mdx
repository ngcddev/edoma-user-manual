Este módulo permite registrar la asistencia diaria de tus estudiantes por
curso y materia, hora de clase por hora de clase.

## ¿Qué encontrarás aquí?

- Un buscador de **curso o materia** y una tarjeta por cada materia que
  dictas (ejemplo: `3-1 — Matemáticas`, `3-1 — Lengua Castellana`).
- Al seleccionar una materia, una tabla de **Registro de Asistencia** con una
  fila por estudiante:

| Columna | Descripción |
| --- | --- |
| Estudiante / Documento / Teléfono | Datos de contacto básicos |
| Horas de clase | Las horas de clase del día para ese curso y materia; si no hay clase programada hoy, muestra "Sin horario configurado para hoy" |
| Observación | Comentario libre sobre la asistencia del estudiante |

- La opción **Marcar asistencia para todos los estudiantes**, que despliega:
  - **Estado para la hora activa**: `Presente`, `Ausente`, `Tardanza`,
    `Justificado`.
  - Una **Observación** general.
  - El botón **Aplicar a todos** (o **Limpiar** para descartar la
    marcación).
- Botones **Editar** y **Mirar asistencia** para pasar entre el modo de
  edición y la vista de solo lectura, y **Registrar Asistencia** para guardar
  los cambios.

<Callout type="warn">
  La marcación masiva **"Aplicar a todos"** solo afecta a las horas activas
  en ese momento (o con registro extemporáneo habilitado); las horas de
  clase que aún no han llegado se marcan cuando llegue su turno.
</Callout>

## Registrar la asistencia de una clase

<Steps>
<Step>

### Selecciona el curso y la materia

En **Asistencias**, busca y selecciona la tarjeta del curso/materia de la
clase que vas a registrar (ejemplo: `3-1 — Inglés`).

</Step>
<Step>

### Marca el estado de cada estudiante

Para cada estudiante, en la columna **Horas de clase**, marca su estado:
`Presente`, `Ausente`, `Tardanza` o `Justificado`.

</Step>
<Step>

### Usa la marcación masiva si aplica

Si todo el curso comparte el mismo estado (por ejemplo, todos presentes),
abre **Marcar asistencia para todos los estudiantes**, selecciona el
**Estado para la hora activa** y haz clic en **Aplicar a todos**.

</Step>
<Step>

### Agrega una observación (opcional)

Si necesitas anotar algo puntual sobre un estudiante, usa el campo
**Observación** de su fila.

</Step>
<Step>

### Guarda el registro

Haz clic en **Registrar Asistencia** para guardar los cambios del día.

</Step>
</Steps>

## Consultar asistencia ya registrada

<Steps>
<Step>

### Cambia a modo de solo lectura

Haz clic en **Mirar asistencia** para ver la asistencia ya registrada sin
riesgo de modificarla por accidente.

</Step>
<Step>

### Vuelve a editar si es necesario

Haz clic en **Editar** para corregir un registro (por ejemplo, si marcaste
por error a un estudiante como ausente).

</Step>
</Steps>
