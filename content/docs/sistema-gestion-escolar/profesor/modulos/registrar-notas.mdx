---
title: Registrar notas
description: Guía de uso de "Registrar notas".
---

Este módulo permite registrar y editar las calificaciones de tus estudiantes
por curso y materia, dentro del período académico activo.

<Callout type="info">
  Agrega aquí capturas de pantalla del registro de notas y de la vista de
  edición.
</Callout>

## ¿Qué encontrarás aquí?

- Un buscador de **curso o materia** y una tarjeta por cada materia que
  dictas (ejemplo: `2-1 — Ciencias Sociales`, `2-1 — Biología`).
- Al seleccionar una materia, una tabla de **Registro de Calificaciones** con
  una fila por estudiante:

| Columna | Descripción |
| --- | --- |
| Estudiante / Documento / Teléfono | Datos de contacto básicos |
| Motivo | Motivo asociado a la nota, si aplica |
| Frase sugerida / Comentarios | Frase predefinida (ejemplo: `Cumple con los criterios evaluados`, `Presenta dificultades que requieren refuerzo`) o comentario libre |
| % Nota | Peso de la actividad dentro de la nota del período |
| Nota | Calificación numérica |
| Estado de Entrega | `Entregado`, `No entregó`, `Justificado`, `Pendiente por excusa` |
| PIAR | Casilla para estudiantes con Plan Individual de Ajustes Razonables |

- La opción **Marcar campos para todos los estudiantes**, para aplicar el
  mismo valor a todo el curso de una vez.
- Un botón **Mirar Notas**, con una vista de solo lectura por estudiante que
  incluye **Nota Definitiva**, **Logro del Periodo / Boletín** (con opción de
  **Personalizar**), **Desempeño Nacional** (`Superior`, `Alto`, `Básico`,
  `Bajo`), **Estado** (`Aprobado`/`Reprobado`) y **Alerta Pedagógica**.

<Callout type="warn">
  Si el sistema muestra **"No se puede subir notas porque no estás dentro del
  rango de fecha estipulada por la ADMINISTRACIÓN"**, el registro de notas
  está temporalmente cerrado para ese período. Debes esperar a que
  Administrativo lo habilite, o solicitar un **registro extemporáneo**.
</Callout>

## Registrar notas de un curso

<Steps>
<Step>

### Selecciona el curso y la materia

En **Notas**, busca y selecciona la tarjeta del curso/materia que quieres
calificar (ejemplo: `2-1 — Física`).

</Step>
<Step>

### Completa la nota de cada estudiante

Para cada estudiante, indica el **% Nota**, la **Nota**, el **Estado de
Entrega** y, si aplica, una frase sugerida o comentario.

</Step>
<Step>

### Usa la marcación masiva si aplica

Si varios estudiantes comparten el mismo estado o comentario, usa **Marcar
campos para todos los estudiantes** para agilizar el registro.

</Step>
<Step>

### Marca el PIAR si corresponde

Activa la casilla **PIAR** para los estudiantes que tengan un Plan
Individual de Ajustes Razonables, de forma que su evaluación se identifique
correctamente.

</Step>
</Steps>

## Consultar o editar notas ya registradas

<Steps>
<Step>

### Abre la vista de edición

Haz clic en **Editar** para ver el detalle de notas ya calificadas: nota
definitiva, logro del período, desempeño nacional, estado y alerta
pedagógica.

</Step>
<Step>

### Personaliza el logro del período (opcional)

Si el logro mostrado no aplica ("Sin logro configurado en el banco para este
nivel"), haz clic en **Personalizar** para redactar uno específico para el
boletín del estudiante.

</Step>
<Step>

### Consulta el detalle del estudiante

Usa **Ver ficha del estudiante** para revisar su información completa antes
de ajustar una nota.

</Step>
</Steps>
