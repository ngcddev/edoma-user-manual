## ¿Qué encontrarás aquí?

- **Registro de Calificaciones**: un buscador de curso o materia y una
  tarjeta por cada curso/materia que dictas (ejemplo: `2-1 — Matemáticas`,
  `6-2 — Inglés`), cada una con su acceso **Seleccionar**.
- Al seleccionar una tarjeta, el encabezado muestra el curso, el número de
  estudiantes y una insignia de **Período Activo**. Debajo, una barra
  colapsable **"Marcar campos para todos los estudiantes"** (el panel
  global — se explica más abajo) y la tabla de **Registro de
  Calificaciones**, con una fila por estudiante:

| Columna | Descripción |
| --- | --- |
| # | Número de fila |
| Estudiante / Documento / Teléfono | Datos de contacto básicos |
| Motivo | Motivo asociado a la nota, si aplica (ejemplo: `Taller`, `Examen`) |
| Frase sugerida / Comentarios | Frase predefinida (ejemplo: `Cumple con los criterios evaluados`, `Presenta dificultades que requieren refuerzo`) o comentario libre |
| % Nota | Peso de la actividad dentro de la nota del período. **Es opcional** — ver la sección "Cómo se calcula la nota definitiva" más abajo. |
| Nota | Calificación numérica |
| Estado de Entrega | `Entregado`, `No entregó`, `Justificado`, `Pendiente por excusa` |
| PIAR | Casilla para estudiantes con Plan Individual de Ajustes Razonables |

- Al pie, cuatro acciones: **Cambiar curso** (vuelve a la lista de
  curso/materia), **Editar** (habilita los campos para registrar o corregir
  notas), **Mirar Notas** (vista de solo lectura) y, si el registro está
  cerrado para el período, el botón se reemplaza por **"No se puede
  registrar notas"** (deshabilitado).
- El **Panel global** ("Marcar campos para todos los estudiantes"): llena el
  % Nota, el estado de entrega o el comentario para **todo el curso de una
  sola vez**, para no perder tiempo cuando la información es la misma para
  todos. Después de aplicarlo, puedes seguir editando la fila de un solo
  estudiante para ajustar su caso puntual, sin que eso afecte a los demás.
- La casilla **PIAR**: márcala cuando la actividad fue adaptada bajo el
  **Plan Individual de Ajustes Razonables** de un estudiante con
  condiciones especiales (objetivos, metodología o criterios de evaluación
  distintos a los del resto del curso). Al marcarla, la calificación queda
  identificada como evaluada bajo PIAR — tanto para ti como para el padre
  de familia, que verá esa marca en el boletín/notas del estudiante.
- **Mirar Notas**: una vista de solo lectura por estudiante que incluye
  **Nota Definitiva**, **Logro del Periodo / Boletín** (con opción de
  **Personalizar**), **Desempeño Nacional** (`Superior`, `Alto`, `Básico`,
  `Bajo`), **Estado** (`Aprobado`/`Reprobado`) y **Alerta Pedagógica**.

<Callout type="warn">
  Si el sistema muestra **"No se puede subir notas porque no estás dentro del
  rango de fecha estipulada por la ADMINISTRACIÓN"**, el registro de notas
  está temporalmente cerrado para ese período. Debes esperar a que
  Administrativo lo habilite, o solicitar un **registro extemporáneo**.
</Callout>

## Registrar notas de un curso

<Steps>
<Step>

### Selecciona el curso y la materia

En **Registro de Calificaciones**, busca y haz clic en **Seleccionar** en la
tarjeta del curso/materia que quieres calificar (ejemplo: `6-2 — Inglés`).
Luego haz clic en **Editar** para habilitar el registro.

</Step>
<Step>

### Completa la nota de cada estudiante

Para cada estudiante, indica el **% Nota**, la **Nota**, el **Estado de
Entrega** y, si aplica, una frase sugerida o comentario.

</Step>
<Step>

### Usa el panel global si aplica

Si varios estudiantes comparten el mismo % Nota, estado o comentario, usa el
**Panel global** ("aplicar a todos los estudiantes") para llenarlo de una
sola vez. Si un estudiante necesita un valor distinto, edítalo después en su
propia fila — el panel global no vuelve a sobrescribirlo.

</Step>
<Step>

### Marca el PIAR si corresponde

Activa la casilla **PIAR** para los estudiantes que tengan un Plan
Individual de Ajustes Razonables, de forma que su evaluación se identifique
correctamente.

</Step>
</Steps>

## Cómo se calcula la nota definitiva

El campo **% Nota** de cada actividad es **opcional**, y el sistema calcula
la nota definitiva del período de una de tres formas, según cómo lo uses:

| Situación | Cómo se calcula |
| --- | --- |
| **1. Ningún % Nota diligenciado** | Cálculo normal: se suman todas las notas y se dividen por la cantidad de notas (promedio simple). |
| **2. Todas las actividades con % Nota** | Cada nota se multiplica por su porcentaje y se suman los resultados. Los porcentajes de todas las actividades deben sumar `100%`. |
| **3. Solo algunas actividades con % Nota** | Las actividades con porcentaje se calculan como en la situación 2; las que no tienen porcentaje se promedian entre sí y ese promedio se multiplica por el **porcentaje restante** hasta completar el `100%`. |

<Callout type="info">
  **Ejemplo de la situación 3**: una actividad vale `5` con `10%`, otra vale
  `4` con `10%`, y hay dos actividades más sin porcentaje: `4` y `4`.
  - Parte con porcentaje: `5 × 10% + 4 × 10% = 0.9` (cubre el `20%`).
  - Parte sin porcentaje: promedio `(4 + 4) / 2 = 4`, multiplicado por el
    `80%` restante → `4 × 80% = 3.2`.
  - Nota definitiva: `0.9 + 3.2 = 4.1` (el `100%`).
</Callout>

## Editar o recuperar una nota registrada

Al hacer clic en **Editar** sobre una nota ya registrada tienes dos
opciones: **actualizar** la nota (por si te equivocaste al digitarla) o
**recuperar** una nota baja, sustituyéndola por una actividad de
recuperación.

- **Actualizar nota**: corrige el valor de una nota ya registrada (por
  ejemplo, digitaste `3.2` en vez de `4.2`). La nota anterior se reemplaza
  sin dejar rastro de que hubo un cambio.
- **Registrar recuperación**: conserva la nota original marcada como
  **"(Reemplazada)"** y agrega la nueva nota como **"(Recuperación)"**, con
  su **Método** (ejemplo: `Oral`, `Escrito`, `Trabajo`) y un comentario. Esta
  trazabilidad queda visible tanto para ti como para el padre de familia en
  el detalle de la nota.

<Steps>
<Step>

### Abre la vista de edición

Haz clic en **Editar** para ver el detalle de notas ya calificadas: nota
definitiva, logro del período, desempeño nacional, estado y alerta
pedagógica.

</Step>
<Step>

### Elige actualizar o recuperar

Usa **Actualizar nota** para corregir un error de digitación, o **Registrar
recuperación** para sustituir una nota baja por una actividad de
recuperación (queda registrado el método y el comentario).

</Step>
<Step>

### Personaliza el logro del período (opcional)

Si el logro mostrado no aplica ("Sin logro configurado en el banco para este
nivel"), haz clic en **Personalizar** para redactar uno específico para el
boletín del estudiante.

</Step>
<Step>

### Consulta el detalle del estudiante

Usa **Ver ficha del estudiante** para revisar su información completa antes
de ajustar una nota.

</Step>
</Steps>

## Modo recuperación

Cuando llega la **fecha de recuperación** que Administración configuró para
el período (en [Períodos](/sistema-gestion-escolar/administrativo/academico/periodos)),
el módulo cambia a modo recuperación: **solo aparecen disponibles los
estudiantes que perdieron el curso**. Los estudiantes que pasaron con
normalidad no necesitan recuperación y no aparecen para registrarles nada.

<Steps>
<Step>

### Espera a que se abra la fecha de recuperación

El modo recuperación solo está disponible dentro del rango de fechas que
Administración definió para **Recuperación** en ese período.

</Step>
<Step>

### Registra solo a los estudiantes listados

Verás únicamente a los estudiantes con nota reprobatoria en el período; los
demás muestran **"No necesita recuperación"** y no se pueden editar.

</Step>
</Steps>
