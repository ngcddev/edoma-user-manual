## Anotaciones públicas y privadas

Los docentes registran anotaciones como **públicas** o **privadas**. Como
padre de familia, **solo puedes ver las anotaciones públicas**: las
privadas se mantienen exclusivamente entre el **director de grupo** del
curso y el **docente que las publicó**, y no aparecen en tu Observador.

## ¿Qué encontrarás aquí?

- El nombre del estudiante consultado.
- El listado de anotaciones **públicas** registradas por los docentes,
  cuando existen.
- Un estado vacío ("Sin anotaciones registradas para este estudiante") cuando
  el docente aún no ha registrado ninguna observación pública.

<Steps>
<Step>

### Abre el módulo Observador
