Este módulo define las escalas de valoración, los desempeños y las reglas de
promoción con las que se califica a los estudiantes, y es la base que usan
[Boletines](/docs/sistema-gestion-escolar/administrativo/sistemas/documentos/boletines)
y [Libro final](/docs/sistema-gestion-escolar/administrativo/sistemas/documentos/libro-final).

<Callout type="warn">
  En un sistema recién creado (MVP/pruebas) esta sección puede mostrarse vacía,
  con el mensaje **"No hay información disponible — No evaluation systems
  registered."**. Esto es normal hasta que se registre el primer sistema de
  evaluación para la institución.
</Callout>

<Callout type="info">
  Agrega aquí una captura de pantalla una vez tengas un sistema de evaluación
  configurado.
</Callout>

## ¿Qué encontrarás aquí?

- El listado de sistemas de evaluación configurados para la institución.
- Si no hay ninguno registrado, un estado vacío indicando que aún no existe
  ningún sistema de evaluación.

<Callout type="info">
  La escala de valoración (rangos numéricos y etiquetas como `Desempeño
  Bajo`, `Básico`, `Alto` y `Superior`) se define actualmente dentro del
  asistente de
  [Boletines](/docs/sistema-gestion-escolar/administrativo/sistemas/documentos/boletines),
  en el paso **Escala**.
</Callout>

## Antes de cerrar el año lectivo

<Steps>
<Step>

### Verifica notas faltantes

Antes de cerrar el
[Libro final](/docs/sistema-gestion-escolar/administrativo/sistemas/documentos/libro-final)
de un curso, confirma que todas las áreas de todos los estudiantes tengan
nota definitiva.

</Step>
<Step>

### Completa lo pendiente

Si faltan notas, complétalas desde este módulo de Sistema de evaluación antes
de continuar con el cierre del año.

</Step>
</Steps>
